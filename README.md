# FilmLab

FilmLab 是面向个人胶片翻拍/扫描的负像还原工作台:导入负像图片,自动检测片基、反转密度、中和橙罩,并还原为可调色的正像。

```text
扫描/翻拍负片(TIFF / JPEG / PNG)
→ 线性透射率(16-bit TIFF 保持全精度)
→ 旋转 / 裁剪
→ 片基检测(默认自动上包络估算,可框选未曝光边缘实测)
→ 相对密度 D = -log10(T / Tbase)
→ Dmin/Dmax 锚点 + 中性像素仿射通道拟合(自动中和橙罩)
→ 10^D 反转 → 自动白平衡(灰世界中位数)× 手动白平衡
→ 曝光 / 对比度 / 高光压缩 / 饱和度
→ 白点归一化 → sRGB 编码
→ 16-bit TIFF / JPEG 导出
```

## 核心流程

1. **打开负片**:支持 8/16 位 TIFF、JPEG、PNG。16 位无 ICC 的 TIFF 按已线性化的扫描数据读取(扫描仪 raw 惯例);8 位文件按显示编码的 sRGB 执行逆传递函数。带 ICC 的 TIFF 会被明确拒绝,避免色彩管理悄悄破坏 16 位精度——请先用 ImageMagick 等工具转换。
2. **片基检测**:默认使用自动估算(三通道联合透射上包络,置信度上限 0.65,界面会提示它不能替代实测片基);也可以在画面上框选一段未曝光片基边缘获得实测值(中位数 + MAD 抗离群)。裁掉边缘后自动估算无法唯一确定真实 Dmin,建议保留一条片基边再框选。
3. **密度反转**:相对密度按通道取 `D = -log10(T/Tbase)`,以 `10^D - 1` 反转为正像。开启"自动中和"后,从低色度像素稳健拟合每通道的仿射响应 `D_c ≈ offset_c + slope_c × 中性密度`(分箱中位数 + Theil–Sen 回归,吸收片基采样残余偏移与通道对比度差异),反转按 `(D_c - offset_c) / slope_c` 归一化,使中性色在整个影调范围保持一致;拟合支撑不足时回退到单锚点方法,接近恒等的拟合会被抑制。预饱和在密度域围绕三通道均值展开色度,默认 1.08。
4. **调色**:曝光(EV)、绕 0.18 中灰的对数域对比度、高光软拐点压缩、饱和度,全部在线性光域完成;自动白平衡用稳健灰世界法(三通道中位数等化,增益限幅 ±2 档)校正场景光源的整体色偏,手动 R/B 增益在其上叠加微调;自动白点把画面中央区域的高光百分位归一化到显示白。sRGB OETF 只在最终量化时应用。
5. **导出**:同一配方在导出时以原始全分辨率重算。TIFF 为 16-bit sRGB Deflate(自有编码器,临时文件 + 原子发布);JPEG 为质量 95、4:4:4 的 8-bit sRGB。两种格式均不含 ICC/XMP,交付编码按未标记 sRGB 约定。

## 开发与验证

```powershell
npm install
npm run check      # typecheck + 全部测试
npm run dev        # 启动工作台
npm run build      # 产物构建
npm run dist:win   # 打包安装程序
```

测试用 `node --test` 直接运行 TypeScript:核心数学(片基/密度/锚点/反转/调色/编码/几何)、端到端合成负片反转、真实文件解码(TIFF 四种压缩、灰度、截断/分块/ICC 拒绝)、导出回读逐通道校验。

## 架构

```text
src/core/        纯函数处理核心,无 Electron 依赖,域标签强制
src/main/        Electron 主进程:解码(TIFF 自有编解码 + sharp)、导出、IPC
src/preload/     contextBridge 桥接(仅两个调用,无文件路径暴露)
src/renderer/    React 界面:画布预览、框选交互、控件面板
```

- 像素域通过 `Raster` 的域标签(`transmission-linear` / `relative-density` / `scene-linear-rgb` / `display-linear`)在每一阶段边界强制校验,显示编码值不可能进入对数密度。
- 渲染进程只收到降采样后的像素载荷与文件名,源文件绝对路径留在主进程;导出由主进程按配方重解码全分辨率并原子写盘。
- 预览在渲染进程用共享核心即时重算(110 ms 防抖);片基采样失败时自动回退到自动估算并提示,不会像旧版那样报错中断。

## 边界

- 不承诺默认模式的相机/扫描仪颜色准确性;白平衡与中和是对橙罩的实用近似,精确颜色需要色卡标定(本版本未内置)。
- 支持条带布局的 8/16 位整数 RGB/灰度 TIFF(无压缩/Deflate/LZW/PackBits,含逐分量水平差分还原);分块、浮点、YCbCr、JPEG 压缩 TIFF 会明确拒绝并提示转换方式。
- 内存:导出按全分辨率浮点栅格重算,24MP 16 位扫描峰值约 1.5–2 GB,超大文件请留意。
- 输出不嵌入 ICC/XMP,交付值即 sRGB。
