# FilmLab 用户手册

本手册对应 FilmLab 0.1.x 当前实现。FilmLab 面向相机翻拍的胶片负片；它不是通用 RAW 显影器，也不会把未标定的相机 RGB 自动变成颜色准确的 sRGB。

## 1. 建立项目与导入

1. 在项目菜单选择“新建项目”，指定一个以 `.filmlab` 结尾的目录。
2. 选择“导入帧”并选取相机 RAW 或 16-bit TIFF。8-bit JPEG/PNG 不能作为负片输入。
3. 为便于长期归档，把源文件与项目目录一起备份，但不必保持原绝对路径。项目保存文件名、尺寸、修改时间和完整 SHA-256，不保存源路径。
4. 源目录移动或文件改名后选择“扫描目录重连”。FilmLab 会按内容指纹恢复连接；内容变化的同名文件不会被误连。

项目会自动保存。Ctrl/⌘+S 可立即刷新保存队列；退出、切换项目和安装更新前也会执行最终保存。只读项目不会原地写入，需使用“另存为”。

## 2. RAW 解码与 A7R V

2×2 Bayer RAW 默认使用 `edge-aware-bayer-v2`：先按局部方向梯度估计绿色，再通过色差插值恢复红蓝。算法版本属于 `decoderFingerprint`；使用旧双线性解码器建立的校准不能自动继承“设备匹配”，应重新制作或验证配置。

Sony A7R V 只有在机型为 `ILCE-7RM5`、ISO 100 且数据范围符合 14-bit 条件时使用内置 Photon Transfer Curve 噪声模型。它只稳定浓密底片的低信号密度估计，不提供相机色彩矩阵，不提升输出色彩可信度。

## 3. 调整负片

- 通用：根据片基和密度范围反转，适合建立可浏览起点，色彩可信度为未校准。
- 默认 C-41：增加预设外观，仍是未校准输出。
- 校准配置：使用特性曲线、3×3 矩阵和可选 3D LUT。只有来源相机型号与解码器指纹都匹配时才是设备匹配。

先确认方向、透视、拉直和片基 ROI，再调曝光、对比度、高光与饱和度。没有未曝光边缘时，优先从同卷其他帧冻结片基；自动估算只作为低置信度起点。除尘、划痕、降噪和锐化在显示编码之前执行。

## 4. 校准配置管理

“导入配置”会验证 `filmlab.calibration-profile` JSON。相同 ID 的更高或不同版本会把当前版本归档；相同 ID/version 但内容不同会被拒绝，避免不可追踪覆盖。

- 导出：保存经过规范化序列化的当前版本，便于迁移到其他机器。
- 历史版本：在版本下拉框选择并恢复；恢复前会归档当前版本。
- 删除：删除本机当前配置及历史。本操作不会删除项目包中已经保存的配置快照。
- 项目迁移：打开项目时会验证并恢复项目引用的校准快照。设备匹配还必须重新核验实际来源身份。

## 5. 单帧与批量导出

顶部格式菜单和检查器可选择：

| 格式 | 用途 | 限制 |
| --- | --- | --- |
| TIFF | 16-bit 高位深交付 | sRGB ICC 只声明编码，不证明颜色准确 |
| JPEG | 8-bit 浏览与分享 | 有损，质量 95 |
| HEIF | 10-bit 高效交付 | 当前写为 AV1/AVIF，扩展名 `.avif` |
| DNG | 16-bit 线性正像交换 | 只允许设备匹配；不是原始 CFA DNG |

“批处理”对当前胶卷顺序导出，逐帧使用已保存配方并在完成后释放大图资源。取消会让当前原子文件安全结束，不再启动后续帧。DNG 批量导出要求每一帧都通过设备匹配检查。

母版优先走 GPU 全分辨率分块管线。GPU 不可用、纹理过大、着色器失败、读回失败或容器写入失败时，应用会清理临时文件并用同一配方执行 CPU 回退。GPU 输出不承诺不同显卡逐位相同；需要像素级确定性回归时使用验收工具的 CPU 路径。

## 6. 色彩可信度判读

- `uncalibrated`：通用/默认预设，可描述为“sRGB 编码的浏览或交付文件”，不可描述为颜色准确母版。
- `profile-unverified`：使用了配置，但相机、解码器或配置身份不完全匹配。
- `device-matched`：相机型号与解码器指纹匹配校准配置，可描述为设备匹配的 linear-sRGB 结果。

TIFF/JPEG/HEIF 的 ICC 与 XMP 会同时保存编码和可信度。不要仅凭“嵌入 sRGB ICC”推断相机颜色已被表征。

## 7. 更新、回滚与恢复

项目菜单显示当前版本和更新状态。安装版自动检查并下载 GitHub Release，只有点击“安装”后才保存项目并重启。Windows 若缓存中存在上一已知良好 NSIS，可手动回滚；新版本连续两次未能显示主窗口时也会自动启动该安装包。首次安装没有旧安装包时不会显示回滚。macOS/Linux 回滚需从发行页重新安装已签名旧版。

项目 schema 可能无法降级。回滚应用前应备份 `.filmlab` 目录，并先阅读 [`migration.md`](migration.md)。主项目损坏时，FilmLab 从最近有效备份只读打开，确认恢复前不会覆盖现场。

## 8. 键盘与无障碍

| 操作 | Windows/Linux | macOS |
| --- | --- | --- |
| 导入帧 | Ctrl+O | ⌘+O |
| 打开项目 | Ctrl+Shift+O | ⌘+Shift+O |
| 立即保存 | Ctrl+S | ⌘+S |
| 导出当前帧 | Ctrl+E | ⌘+E |
| 批量导出 | Ctrl+Shift+E | ⌘+Shift+E |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y | ⌘+Z / ⌘+Y |
| 前一帧 / 后一帧 | Alt+← / Alt+→ | Option+← / Option+→ |
| 快捷键帮助 | F1 | F1 |

Tab 可遍历控件；首次聚焦页面时可使用“跳到主工作区”。状态通知通过 live region 发布。系统启用“减少动态效果”时，界面会压缩动画。快捷键不会在文本输入框、下拉框或可编辑内容中截获文字编辑。

## 9. 故障排查与安全备份

导出失败时先检查目标目录写权限和磁盘空间，再确认 RAW sidecar 与当前平台匹配。不要在唯一项目或相机卡上做恢复试验；先复制项目与源文件。日志、项目会话索引和诊断包可能包含本机路径，发送前必须脱敏。详细步骤见 [`diagnostics.md`](diagnostics.md)，发行验证见 [`release.md`](release.md)。
